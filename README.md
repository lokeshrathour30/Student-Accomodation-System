# Student Accommodation System
A menu-driven C++ project that helps students find suitable accommodation and allows property owners to manage their listings.

## Features
- Search and filter accommodations by rent, location, type, and facilities.
- View property details and recently viewed listings.
- Submit and manage inquiries.
- Register owners and manage property listings.
- Store data using CSV files.

## Technologies
- **Language:** C++
- **Concepts:** OOP, DSA, File Handling
- **Data Structures:** Linked List, Stack, Queue

## How to Run
Compile using GCC:

```bash
g++ -std=c++17 Student_Accommodation_System_Easy_Filters.cpp -o accommodation.exe
```

Run on Windows:

```powershell
.\accommodation.exe
```

Keep `accommodations.csv` in the program's working directory.
